# write-x

## Purpose

Adapts the reviewed article for X and chooses a concise single post or a short thread only when the idea needs progression.

## Inputs and outputs

Input is `blog-draft.md` and a matching, passing `blog-review.md`. Output is `x-draft.md` with a recommended `single` or `thread` format and status `draft_for_review`.

## Relationships

It runs after `review-blog`, inherits the article’s claim boundaries, and never publishes, schedules, or uses X APIs.
