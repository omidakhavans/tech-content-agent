# create-content

## Purpose

Orchestrates the existing skills from one subject. It inspects existing artifacts, runs or reuses stages, applies stop conditions, and records the result.

## Inputs and outputs

Input is a subject, with optional resources, repository scope, notes, or an existing subject folder. Output is `content-run-summary.md` plus the component artifacts produced by each stage.

## Relationships

The normal order is research → resources → evidence context → blog → review → LinkedIn/X. It coordinates; it does not duplicate research, writing, review, publishing, scheduling, or API responsibilities.
