# tech-research-work

## Purpose

Investigates what was actually built or changed in a local repository. It prefers source, tests, configuration, docs, and Git evidence over memory.

## Inputs and outputs

Input is a subject and an optional repository scope. Output is `research-report.md` under `.techcontent/<title-slug>/`, with relevant files, commits, decisions, problems, evidence references, and unknowns.

## Relationships

This is the first research stage. Its report feeds `build-evidence-context`; it does not write prose or use external services. Use it when a later article is based on verified engineering work.
