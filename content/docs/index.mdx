# tech-content-agent

`tech-content-agent` is a Phase 1 prototype for turning engineering work into grounded technical content. It uses Codex as the runtime and a set of focused skills as the workflow contract.

The project does not publish content, call social APIs, or hide state in a database. Research, context, drafts, reviews, and run summaries are Markdown files that can be inspected and reviewed in Git.

## What it solves

Writing directly from memory makes it easy to blur what was built, what was learned from external sources, and what is only an interpretation. This project inserts explicit evidence and review stages before a canonical article is transformed into social drafts.
