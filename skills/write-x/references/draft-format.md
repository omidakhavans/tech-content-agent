## Post/Thread Content

For `single`, write one post.

For `thread`, number each post and make the progression coherent:

`problem -> approach -> discovery -> technical insight -> takeaway`

Guidance:

- Preserve what the user actually built, tested, or learned.
- Adapt to X rather than simply shortening the blog.
- Keep claims grounded in `blog-draft.md` and `blog-review.md`.
- Avoid claims flagged by review.
- Avoid engagement bait, unnecessary hashtags, generic promo phrasing, and obvious AI-generated patterns.
- Keep each post concise.
