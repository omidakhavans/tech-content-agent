# LinkedIn Draft Format

Use this structure for `write-linkedin` output. Keep it platform-appropriate, technically grounded, and easy for the user to review.

## Status

`draft_for_review`

## Post

Write the LinkedIn post draft.

Guidance:

- Open with a specific engineering insight, tension, or lesson.
- Avoid clickbait and vague motivational framing.
- Keep paragraphs short.
- Preserve what the user actually built or learned.
- Explain technical substance clearly but compactly.
- Distinguish personal experience from general technical claims.
- Avoid claims flagged by `blog-review.md`.
- Avoid obvious AI-generated phrasing.
- Do not overuse bullets, emojis, hashtags, or calls to action.
